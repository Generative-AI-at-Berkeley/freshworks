# Decisions

Architecture decision records. Each one is short: the context, what we
decided, and what it costs us.

- Copy [0000-template.md](0000-template.md), take the next number, open a PR.
- Status is `proposed` until the PR merges, then `accepted`.
- Never edit an accepted ADR to change the decision. Write a new one that
  supersedes it, and set the old one's status to `superseded by NNNN`.
